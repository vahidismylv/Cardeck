# Cardeck

A loyalty card wallet for iOS.

Cardeck keeps store, fuel, pharmacy and coffee cards in one place, stacked the way Apple Wallet stacks passes. 
Each card is a holographic surface that catches the light as you tilt the phone. 
Tap a card and it opens full screen with its barcode, the screen brightness rises so the scanner reads it in one pass,
and a swipe down puts it back on the stack.

Everything stays on the device. No account, no network, no analytics.

## Features

- Cards with a name, number, category, note and a choice of eight holographic finishes
- Code128, QR and PDF417 barcodes, generated on the device
- Automatic screen brightness boost while a code is on screen
- Reorder the stack by dragging, or sort by most used and alphabetically
- Delete with undo
- Haptic feedback throughout

Built with UIKit for iOS 18 and later. No third-party dependencies.
